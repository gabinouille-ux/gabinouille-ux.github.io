Privacy Policy

Last updated: November 22, 2026 (YouTube API Services section added)

GTA VI Clips ("the tool") is a personal application used only by its owner to publish their own gameplay clips to their own TikTok account and YouTube channel.

Data we access

  • TikTok: basic profile information (open ID, display name) and permission to upload or publish videos to the owner's account.
  • YouTube / Google: permission to upload videos to the owner's channel and read the channel name.

How data is used

This access is used only to publish the owner's own clips. No data is sold, shared with third parties, used for advertising, or used to train models.

Storage

Access tokens are stored only on the owner's computer, in a file readable by the owner only. Nothing is stored on a server.

Data from other people

The tool does not collect, read or store data about any other user.

Deleting access

Access can be revoked at any time from TikTok settings (Security > Manage app permissions) and from the Google Account page (Security > Third-party connections). Deleting the token file on the owner's computer also removes all stored access.

YouTube API Services

GTA VI Clips uses the YouTube API Services to upload videos to the owner's YouTube channel. By using GTA VI Clips you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

YouTube API data used: the channel name (to confirm the connected channel) and the ID of each uploaded video (kept in a local log file on the owner's computer). No other YouTube data is collected, stored, shared or sold.

The owner can revoke the tool's access at any time from the Google security settings page. Deleting the local token file removes all stored access immediately; the local log can be deleted at any time.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
